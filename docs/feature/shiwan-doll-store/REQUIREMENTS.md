# 石湾公仔海外独立站 需求分析

> 创建日期: 2026-01-21
> 状态: 待确认

## 业务背景

### 当前存在的问题
- 石湾陶瓷公仔传统销售渠道受限，难以触达海外市场
- 缺乏品牌展示和故事讲述的独立渠道
- 无法掌握海外客户数据，难以进行精准营销

### 用户痛点
- 东南亚藏家缺乏便捷的线上购买渠道
- 石湾陶艺文化传承故事缺乏有效传播平台
- 中高端收藏品需要专业的品牌展示和信任体系

### 业务机会
- 石湾公仔在东南亚"名噪南洋"，历史认知度高
- 华人收藏文化成熟，已有稳定藏家群体
- DTC模式可以获得比平台高10-15%的溢价空间

---

## 用户故事

**作为** 海外石湾公仔收藏家和爱好者
**我想要** 通过独立站浏览、了解并购买石湾陶瓷公仔
**以便** 获得完整的购物体验、了解产品背后的文化故事，并享受比平台更优质的服务

## 功能描述

### 1. 商品展示 (P0)
- 商品列表页：展示所有可售公仔产品
- 商品详情页：产品图片、价格、库存、描述
- 产品分类：按系列、价格区间分类
- 搜索功能：关键词搜索商品

### 2. 购物流程 (P0)
- 购物车：添加/删除商品、数量调整
- 结算流程：地址填写、配送方式选择、支付
- 订单确认：支付成功后生成订单号

### 3. 支付集成 (P0)
- Stripe：支持信用卡支付
- PayPal：支持PayPal账户支付
- 支付宝：支持人民币支付
- 微信支付：支持微信扫码支付

### 4. 订单管理 (P0)
- 订单状态：待支付、已支付、已发货、已完成、已取消
- 订单详情：商品信息、配送地址、支付方式

### 5. 品牌故事 (P1)
- 关于我们：石湾陶艺历史、大师传承
- 产品文化：每款产品的文化背景介绍

### 6. 客户服务 (P1)
- 联系方式：邮箱、WhatsApp
- FAQ常见问题
- 物流信息：配送时效说明

## 交互流程

### 用户购买流程

1. **浏览商品**
   - 访问首页 → 查看推荐商品
   - 点击商品列表/分类 → 筛选感兴趣的产品

2. **查看详情**
   - 点击商品卡片 → 进入商品详情页
   - 查看产品图片、描述、价格、文化故事
   - 选择规格（如有）、数量

3. **加入购物车**
   - 点击"加入购物车" → 添加成功提示
   - 可继续购物或立即结算

4. **结算支付**
   - 点击购物车图标 → 查看购物车
   - 填写配送地址（新加坡地址）
   - 选择配送方式（直邮/海外仓）
   - 选择支付方式（Stripe/PayPal/支付宝/微信支付）
   - 确认订单 → 跳转支付页面

5. **订单完成**
   - 支付成功 → 显示订单确认页
   - 接收订单确认邮件
   - 跟踪订单状态

### 管理员后台流程（简化版）

1. **商品管理**
   - 添加/编辑/删除商品
   - 管理商品图片
   - 调整库存和价格

2. **订单管理**
   - 查看所有订单
   - 更新订单状态
   - 查看订单详情

- [ ] 用户可以将商品加入购物车
- [ ] 用户可以完成购物车结算流程
- [ ] 用户可以选择配送地址（支持新加坡地址）
- [ ] 用户可以使用Stripe完成支付
- [ ] 用户可以使用PayPal完成支付
- [ ] 用户可以使用支付宝完成支付
- [ ] 用户可以使用微信支付完成支付
- [ ] 支付成功后系统正确创建订单
- [ ] 用户可以在订单页面查看订单状态
- [ ] 管理员可以在后台添加商品
- [ ] 管理员可以在后台管理订单状态

### P1 重要功能（时间允许）

- [ ] 用户可以搜索商品
- [ ] 用户可以浏览品牌故事和产品文化介绍
- [ ] 用户可以查看FAQ和联系客服
- [ ] 管理员可以在后台编辑订单信息

### 非功能性要求

- [ ] 页面加载时间 < 3秒
- [ ] 移动端响应式适配
- [ ] 支持英文界面（目标市场为新加坡）
- [ ] 支持新币（SGD）和人民币（CNY）定价
- [ ] 支付成功率 > 95%
- [ ] 订单数据实时保存，无数据丢失

## 优先级

- **P0（核心功能）**: 商品展示、购物车、支付、订单管理
- **P1（重要功能）**: 搜索、品牌故事、客户服务
- **P2（增强功能）**: 用户系统、收藏功能、评价系统（后续迭代）

## 技术约束

- 前端框架：Next.js 14+（React 18+）
- 后端框架：Next.js API Routes
- 数据库：PostgreSQL
- 支付集成：Stripe SDK、PayPal SDK、支付宝SDK、微信支付SDK
- UI组件库：shadcn/ui（基于Radix UI和Tailwind CSS）
- 状态管理：React Context API / Zustand
- 表单处理：React Hook Form + Zod
- 部署平台：Vercel
- 开发周期：1-2周

## 目标市场

### 首选市场：新加坡（东南亚）

**核心优势**：
- 石湾公仔在东南亚认知度高
- 华人用户占比高，文化距离近
- 物流成本低（直邮7-12天）
- 电商市场成熟

**市场特征**：
- 主流语言：英文
- 主要货币：新币（SGD）
- 主流支付方式：信用卡、PayPal、PayNow
- 电商平台：Shopee、Lazada竞争激烈，DTC差异化机会大

## 风险和限制

### 技术风险
- 支付集成可能遇到SDK兼容性问题
- 快速开发可能导致代码质量妥协
- MVP功能有限，可能无法满足所有用户需求

### 业务风险
- 新市场接受度未知
- 物流成本可能影响利润
- 支付成功率受外部因素影响

### 时间风险
- 1-2周开发周期紧张，需要合理控制功能范围
- 支付集成可能需要额外时间调试
