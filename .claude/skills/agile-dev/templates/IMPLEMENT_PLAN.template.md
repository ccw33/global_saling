### Bug 处理流程

1. **Bug 发现**: QA 测试或用户反馈
2. **Bug 报告**: 创建 Bug 单，包含复现步骤
3. **Bug 修复**: 开发人员修复
4. **回归测试**: QA 验证修复
5. **Bug 关闭**: 验证通过后关闭

### Bug 优先级定义

| 优先级 | 定义 | 响应时间 |
|--------|------|----------|
| P0 | 阻塞性 Bug，无法使用 | 立即 |
| P1 | 重要功能受影响 | 24小时 |
| P2 | 次要功能受影响 | 3天 |
| P3 | 轻微问题，不影响使用 | 下个版本 |
