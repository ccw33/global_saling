## 🧪 测试指南

### 手动测试步骤

1. **启动开发服务器**
   ```bash
   cd frontend
   npm run dev
   ```

2. **访问测试页面**
   - 中文首页: http://localhost:3000/zh
   - 英文首页: http://localhost:3000/en
   - 产品列表: http://localhost:3000/zh/products
   - 关于页面: http://localhost:3000/zh/about

3. **功能测试清单**

   **语言切换测试**:
   - 点击导航栏的 "EN" 按钮
   - 验证页面内容切换为英文
   - 验证 URL 从 `/zh/*` 变为 `/en/*`
   - 点击 "中文" 按钮，验证切换回中文

   **货币切换测试**:
   - 点击货币下拉菜单（$ USD）
   - 选择 "S$ SGD"
   - 验证所有产品价格显示为新加坡元
   - 切换其他货币（MYR, CNY）验证

   **产品筛选测试**:
   - 访问产品列表页
   - 点击分类按钮（如 "经典人物"）
   - 验证 URL 更新: `?category=classic`
   - 验证页面只显示该分类的产品
   - 点击 "全部" 按钮，验证显示所有产品

   **产品详情测试**:
   - 点击任意产品卡片
   - 验证进入产品详情页
   - 验证显示：产品图片、名称、价格、描述
   - 验证大师信息显示（如果有）
   - 验证相关产品推荐显示
   - 点击 "询价" 按钮，验证跳转到联系页面

   **响应式测试**:
   - 调整浏览器窗口大小
   - 验证布局在不同屏幕尺寸下正常
   - 移动端验证汉堡菜单功能
