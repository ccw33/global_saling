## 🐛 常见问题排查

### 问题1: 页面显示 "Database connection failed"

**原因**: PostgreSQL 未启动或连接配置错误

**解决方案**:
```bash
# 检查 PostgreSQL 是否运行
docker ps | grep postgres

# 或检查 OrbStack
psql -h localhost -p 5433 -U bulletin -d bulletin_dev -c "SELECT 1;"
```

### 问题2: 图片显示破损

**原因**: 产品图片未上传或URL错误

**解决方案**:
- 这是正常的，当前使用 placeholder 图片
- 后续需要上传实际产品图片

### 问题3: TypeScript 错误

**原因**: 类型定义问题

**解决方案**:
```bash
# 检查类型错误
npm run build
```

### 问题4: 端口已被占用

**原因**: 3000端口被其他应用占用

**解决方案**:
```bash
# 查找占用端口的进程
lsof -i :3000

# 杀死进程
kill -9 <PID>

# 或使用其他端口
PORT=3001 npm run dev
```
